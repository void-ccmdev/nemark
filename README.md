# Nemark Game Engine
## A Free and Open-Source Source like C++ game engine

>[!Note]
> THIS GAME ENGINE IS NOT FUNCTIONAL YET!

Required dependencies 
 ```bash
 //Arch linux
 pacman -S cmake glfw
 //FreeBSD
 pkg install cmake glfw
 ```

How to setup build?
```bash
cmake -B build
```

How to build?
```bash
cmake --build build
```
